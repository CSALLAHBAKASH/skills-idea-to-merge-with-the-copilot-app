# Mona's Bookmark Manager Roadmap

A quick look at the features we want to add and the risks we want to address.

| Area | Item | Type | Priority |
|---|---|---|---|
| Bookmarks | Search & filter bookmarks | 🚀 | High |
| Bookmarks | Edit a bookmark | 🚀 | Medium |
| Organization | Tags or folders | 🚀 | Medium |
| Portability | Import & export bookmarks | 🚀 | Low |
| Bookmarks | Duplicate slugs on re-add | 🐞 | Medium |
| Validation | Empty URLs may be accepted | 🐞 | High |
| Data safety | Bookmarks lost when localStorage is cleared | 🐞 | Medium |

## 🚀 Planned features

- 🔖 Search & filter bookmarks — priority: high
- ✏️ Edit a bookmark — priority: medium
- 🏷️ Organize bookmarks with tags or folders — priority: medium
- 📦 Import and export bookmarks — priority: low

## 🐞 Known bugs & risks

- 🐞 Duplicate slugs can occur when a bookmark is re-added — priority: medium
- 🐞 Empty URLs may pass validation — priority: high
- ⚠️ Clearing localStorage can permanently remove saved bookmarks — priority: medium
